System and EVB basis
====================

``System`` is the calculator-independent driver for one reactive force call.
``EVBBasis`` builds the diabatic states it diagonalizes. ``EVBSystem`` is the
fixed-state alternative behind :class:`DynamicTopology.ase.EVB`.
